# Ahmad Bin Sadiq - Portfolio Website

A premium, professional portfolio website for Ahmad Bin Sadiq, an AI-Powered Manufacturing Consultant, 
Lean Six Sigma Master Black Belt, and Industrial Engineer.

## Features

- **7 Pages**: Home, About, Services, Case Studies, Industries, Certifications, Resume, Contact
- **Advanced Animations**: Framer Motion scroll animations, hover effects, floating elements
- **Data Analytics Visualizations**: Interactive counters, charts, progress bars
- **Light Theme**: Professional, clean design with positive energy
- **Responsive**: Fully responsive design for all devices
- **SEO Optimized**: Meta tags, structured data, semantic HTML

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons

## Pages

1. **Home**: Hero section with animated stats, services preview, industries preview, CTA

4. **Case Studies**: 6 detailed case studies with challenges, solutions, results
5. **Industries**: Industry-specific solutions for 6+ sectors
6. **Certifications**: Academic excellence, professional certifications, technical expertise
7. **Resume**: Full resume with download option
8. **Contact**: Contact form, consulting areas, industries supported

## Deployment

### Deploy to Netlify

1. Build the project:
```bash
npm run build
```

2. The `dist` folder will be created with static files

3. Deploy to Netlify:
   - Go to [Netlify](https://www.netlify.com/)
   - Drag and drop the `dist` folder
   - Or connect your GitHub repository

### Deploy to GitHub Pages

1. Update `next.config.js`:
```javascript
const nextConfig = {
  output: 'export',
  basePath: '/your-repo-name',
}
```

2. Build and push to GitHub

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
